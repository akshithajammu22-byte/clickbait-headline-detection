REST API Endpoints

JSON HTTP API
POST /api/predict

Evaluates a single headline string and returns prediction, probabilities, linguistic features, token highlights, and neutral rephraser suggestion.

Sample Request:
curl -X POST http://localhost:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"headline": "10 Mind-Blowing Secrets Flight Attendants Don\x27t Want You To Know!"}'
Sample Response:
{
  "headline": "10 Mind-Blowing Secrets...",
  "prediction": "Clickbait Headline",
  "is_clickbait": true,
  "clickbait_probability": 94.8,
  "legitimate_probability": 5.2,
  "risk_level": "Critical Clickbait",
  "linguistic_breakdown": {
    "sensationalism_score": 9.5,
    "capitalization_pct": 28.2,
    "all_caps_words": 0,
    "exclamation_marks": 1,
    "listicle_pattern": true
  },
  "neutral_rewrite": "Overview of Flight Attendant Protocols."
}
POST /api/batch

Evaluates multiple headlines in batch via JSON array or multipart CSV file upload.

Fetches comprehensive multi-model benchmark evaluation metrics, confusion matrices, and top features.
